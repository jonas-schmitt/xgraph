# Security policy

Report suspected vulnerabilities through the repository's Security tab,
using **Report a vulnerability** when available, or the
[private advisory form](https://github.com/jonas-schmitt/xgraph/security/advisories/new).

Repository administrators must enable private vulnerability reporting and verify
that route before a public release. This document does not confirm that the
feature is currently enabled. If the private route is unavailable, request a
private contact through an issue without including vulnerability details.

Include the affected source commit, environment, impact and a small synthetic
reproducer. Remove credentials, private graph data and personal information from
logs. Share sensitive details only through an agreed private channel; do not put
them in public issues, pull requests or example files.

The APIs are experimental. Identify the exact commit in each report so that
maintainers can reproduce the affected version.
