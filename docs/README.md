## Research records (historical)

This is a curated library source profile. Historical research records,
experiment launchers, registrations, datasets and results are retained separately
from this archive. Their absence is not evidence of a successful experiment.
See [reproduction scope](reproducing.md) before interpreting research or timing
claims. The public CPU examples establish only the behaviors they check.
